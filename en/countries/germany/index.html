Postlagernd · Deutsche Post

In short. Germany: poste restante is called “Postlagernd” and is run by Deutsche Post. A letter is held: 7 working days. Cost: Standard postage. ID document: unconfirmed.

No specific fees. Not to be confused with the "Lagerservice" (€15.90 to €17.90), which is a different service.

  • For letters. Parcels are not mentioned on the official page.
  • A password (Kennwort) can replace the name for ordinary mail. ID requirement: not officially specified.
  • Not all branches offer the service: use the "Postlagernd" filter in the Postfinder.
